# مطاعم — تطبيق مستقل (XTRA)

هذا المجلد **نسخة كاملة للتشغيل والتعبئة لاحقاً في EXE**: يتضمن **الواجهة (React)** و**الخادم (FastAPI)** و**واجهة التدفق النقدي** داخل `ui/modules/cashflow` — **دون الاعتماد على `XTRA_WEB\backend` أو `XTRA_WEB\ui` خارج هذا المجلد** بعد النسخ.

واجهة موحّدة لأدوار **كاشير / محاسب / مدير / مطوّر** مع `VITE_XTRA_API` → خادم محلي داخل `backend/`.

## التشغيل السريع

1. من جذر المشروع `مطاعم`:
   - انسخ `.env.example` إلى `.env` وعدّل العناوين إن لزم.
2. شغّل `run.bat` (أو `npm install` ثم `npm run dev`).
3. المتصفح: **http://127.0.0.1:5290**
4. دخول تجريبي بالرموز:
   - `1001` كاشير  
   - `2001` محاسب  
   - `3001` مدير  
   - `9001` مطوّر  

## الخدمات الخلفية (كلها داخل هذا المجلد)

| الخدمة | المسار | الأمر |
|--------|--------|--------|
| API إكسترا | `مطاعم\backend\` | `cd backend` ثم `python api_server.py` → منفذ **2288** (أو `set XTRA_API_PORT=...`) |
| إعدادات قاعدة البيانات | `مطاعم\config\settings.json` | انسخ من `config\settings.example.json` وعدّل |
| التدفق النقدي الثابت | `مطاعم\ui\modules\cashflow\` | يُخدمه نفس الخادم تحت `/modules/cashflow/` |

**تثبيت بايثون (مرة واحدة):** من مجلد `backend`: `pip install -r requirements.txt`

متغيرات البيئة:

- `VITE_XTRA_API` — افتراضي `http://127.0.0.1:2288`
- `VITE_NUIT_BASE` — افتراضي `http://127.0.0.1:8000`

## ما تم تنفيذه

- تسجيل دخول حسب الدور (تجريبي).
- كاشير: لوحة، POS، صرف مصروفات، **تدفق نقدي** (إكسترا `modules/cashflow`)، **تقارير حسابات** (`/api/reports`).
- محاسب: لوحة، تدفق نقدي، مشتريات، تقارير حسابات.
- مدير: داشبورد، تقارير حسابات، تدفق نقدي.
- مطوّر: اتصال القاعدة، تهيئة، مستخدمون، **تقارير حسابات** (للاختبار).
- مطوّر: **إعدادات الاتصال** (PUT عبر إكسترا)، توجيه لـ `sql/`، **إدارة مستخدمين محلية** (localStorage).

## ميزات مقترحة (لم تُذكر وتستحق الإضافة)

- جدولة الطلبات والحجوزات مع تذكيرات (TBL126 إن رُبطت).
- تكامل مطبخ: WebSocket أو polling لـ `kitchen_notifications`.
- صلاحيات دقيقة لكل زر (سياسة على الخادم وليس المتصفح فقط).
- نسخ احتياطي تلقائي لـ `config/restaurant/*.json`.
- سجل تدقيق (Audit) لحركات الصرف والمشتريات.

## مجلد SQL

- `sql/init_app_users.sql` — قالب جدول مستخدمي التطبيق (معلّق؛ نفّذه يدوياً إذا رغبت).
